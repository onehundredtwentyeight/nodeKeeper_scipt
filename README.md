# nodeKeeper & remnainstall

Automated, zero-intervention deployment and management suite for **Remnawave Nodes** with built-in system hardening, native Cloudflare WARP, multi-mode Caddy selfsteal reverse proxy, and scheduled autonomous maintenance.

---

## Quick Start (One-Line Install via `curl`)

### 1. Interactive One-Prompt Setup (Ask Once, Run Unattended)
Run on a fresh Ubuntu/Debian node as `root`:

```bash
curl -fsSL https://raw.githubusercontent.com/onehundredtwentyeight/nodeKeeper_scipt/main/install.sh | bash
```
*(Or using the `remnainstall` entry point)*:
```bash
curl -fsSL https://raw.githubusercontent.com/onehundredtwentyeight/nodeKeeper_scipt/main/remnainstall | bash
```

The script asks for all parameters **once at the very beginning**, displays a summary, runs IP & censorship diagnostics (`ipregion` + `censorcheck`), and then completes the entire installation without any further prompts.

### 2. Zero-Touch Unattended Setup (With Config File)
Copy [`nodekeeper.conf.example`](nodekeeper.conf.example) to `nodekeeper.conf`, fill in your values, and execute:

```bash
curl -fsSL https://raw.githubusercontent.com/onehundredtwentyeight/nodeKeeper_scipt/main/install.sh | bash -s -- --config /path/to/nodekeeper.conf --yes
```

You can also pass a remote config URL or CLI flags directly:
```bash
curl -fsSL https://raw.githubusercontent.com/onehundredtwentyeight/nodeKeeper_scipt/main/install.sh | bash -s -- \
  --yes \
  --hostname "kvn-nl-01" \
  --mode "selfsteal-multi" \
  --domain "node.example.com" \
  --cf-token "cfut_..." \
  --panel-ip "203.0.113.10" \
  --secret-key "eyJub2RlQ2VydFBlbSI6..."
```

## Features

1. **Pre-Flight IP & Censorship Checks**:
   Runs `ipregion.sh` and `censorcheck.sh` before applying system modifications and saves reports to `/opt/nodekeeper/logs/`.
2. **Full Custom Hostname**:
   Prompts for the exact hostname without forcing a prefix.
3. **Core Networking & Security Stack**:
   - Enables TCP **BBR** (`fq` + `bbr`).
   - Installs and configures **Fail2ban** protecting the SSH port.
   - Installs **Docker Engine** & Docker Compose plugin.
   - Configures **UFW** firewall (opens SSH, 80, 443, and restricts `NODE_PORT` `2222` exclusively to your `PANEL_IP`).
4. **System Hardening**:
   - Creates a dedicated admin user (default: `node`) with an autogenerated 20-character password.
   - Grants `sudo` and `docker` group permissions.
   - Configures SSH public key authentication (auto-detects `/root/.ssh/authorized_keys` or accepts a custom key).
   - Disables root SSH login (`PermitRootLogin no`) and password authentication (`PasswordAuthentication no`).
5. **Unattended Cloudflare WARP**:
   - Automatically provisions native WireGuard WARP via `wgcf` with `Table = off` and `PersistentKeepalive = 25` (`wg-quick@warp` systemd service) without interactive prompts.
6. **Three Native Remnanode Installation Modes**:
   - `basic` — Runs `remnanode` container only.
   - `selfsteal-single` — Runs `remnanode` + `caddy:latest` listening on `/dev/shm/nginx.sock` with PROXY protocol and HTTP-01 challenge for single-server domains.
   - `selfsteal-multi` — Runs `remnanode` + custom-built Caddy (`caddy-dns/cloudflare` plugin) using Cloudflare DNS-01 challenge (`CLOUDFLARE_API_TOKEN`) so multiple servers can share a selfsteal domain.
7. **Autonomous Maintenance & OS Updates**:
   - Schedules a self-rescheduling cron job (default: randomized 5–10 days interval) that pulls fresh Docker images, runs `apt upgrade`, executes optional custom hooks, runs censorship diagnostics, rotates logs older than 30 days, and reboots cleanly.

## `nodeKeeper` CLI Management Utility

After installation, run `nodeKeeper` from anywhere (available to both `root` and the created admin user):

```bash
# Open interactive control panel
nodeKeeper

# Show full status (containers, WARP, Fail2ban, BBR, maintenance cron)
nodeKeeper status

# Switch installation mode on the fly
nodeKeeper mode basic
nodeKeeper mode selfsteal-single
nodeKeeper mode selfsteal-multi

# Control maintenance schedule
nodeKeeper schedule status
nodeKeeper schedule enable
nodeKeeper schedule disable
nodeKeeper schedule freq 5 10
nodeKeeper schedule logs true
nodeKeeper schedule extra-cmd "docker system prune -af"

# Start / Stop / Restart node containers
nodeKeeper restart

# Temporarily disable server (stops containers & closes proxy ports in UFW)
nodeKeeper disable

# Re-enable server
nodeKeeper enable

# View logs
nodeKeeper logs remnanode
nodeKeeper logs caddy
nodeKeeper logs maint
nodeKeeper logs tests

# Full clean uninstall
nodeKeeper uninstall
```
